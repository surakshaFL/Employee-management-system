# Employee Management System

A web-based Employee Management System built with **React, TypeScript, and Vite**.

## Features

* Employee dashboard
* Add, edit and delete employees
* Employee details
* Search and filter employees
* Responsive UI
* TypeScript for type-safe development

## Tech Stack

* React
* TypeScript
* Vite
* CSS

## Getting Started

### 1. Clone the repository

```bash
git clone git@github.com:surakshaFL/Employee-management-system.git
cd Employee-management-system
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open the URL shown in the terminal to view the application.

## Build for Production

```bash
npm run build
```
